# Security

Backdrop renders local, generated backgrounds and reads and writes only the files you choose and its own library. Please report a security problem privately through this repository's **Security** tab (**Report a vulnerability**) rather than in a public issue, with the version, what you did, what happened, and the smallest case that shows it.

Releases are ad-hoc signed and not notarized. A binary is supported only when it is published here with a version, a source revision and checksums.
